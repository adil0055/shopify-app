# Admin UI Extension — VTO Product Configuration

## Overview

This Admin UI Extension allows merchants to configure Virtual Try-On settings **directly from the Shopify product admin page**, eliminating the need to navigate to the app dashboard.

## Features

✅ **Embedded in Product Admin** — Appears as a block on the product details page  
✅ **Toggle VTO On/Off** — Simple checkbox to enable/disable VTO for each product  
✅ **Visual Image Selector** — Radio buttons with image thumbnails for easy selection  
✅ **Real-time Save** — Saves configuration to your app backend via API  
✅ **Error Handling** — User-friendly error and success messages  
✅ **Loading States** — Spinner while fetching/saving data

## Technical Architecture

### Frontend (Admin UI Extension)
- **Location**: `extensions/vto-product-config/src/BlockExtension.jsx`
- **Framework**: Preact (Shopify's admin extension framework)
- **Target**: `admin.product-details.block.render`
- **Data Access**: Shopify provides `productId`, `title`, and `images` via the admin context

### Backend API
- **Location**: `app/routes/app.api.vto-product-config.jsx`
- **Methods**:
  - `GET` — Fetch existing VTO configuration for a product
  - `POST` — Save VTO configuration (enable/disable + selected image)
- **Authentication**: Uses Shopify admin session (embedded app auth)

### Data Flow

```
Product Admin Page
       ↓
Admin UI Extension loads
       ↓
GET /app/api/vto-product-config?productId=gid://...
       ↓
Backend queries ProductVtoConfig table
       ↓
Returns { enabled, selectedImageId, selectedImageUrl }
       ↓
Extension displays current state
       ↓
Merchant toggles/selects image
       ↓
POST /app/api/vto-product-config
       ↓
Backend upserts ProductVtoConfig
       ↓
Success message shown
```

## Database Schema

The extension uses the existing `ProductVtoConfig` model:

```prisma
model ProductVtoConfig {
  id               String   @id @default(cuid())
  shop             String
  productId        String   // GID format: gid://shopify/Product/123
  productTitle     String
  productImage     String
  selectedImageId  String   // GID of the selected image
  selectedImageUrl String   // Full URL of the selected image
  isEnabled        Boolean  @default(true)
  createdAt        DateTime @default(now())
  updatedAt        DateTime @updatedAt

  @@unique([shop, productId])
}
```

## Testing the Extension

1. **Start dev server** (if not already running):
   ```bash
   npm run dev
   ```

2. **Open a product in Shopify admin**:
   - Navigate to Products → [Any Product]
   - Scroll down to see "Virtual Try-On Settings" block

3. **Configure VTO**:
   - Toggle "Enable Virtual Try-On"
   - Select an image
   - Click "Save VTO Settings"

4. **Verify on storefront**:
   - The "Try On" button should appear on the product page
   - Clicking it should use the selected image for VTO

## Benefits Over Dashboard Onboarding

| Dashboard Onboarding | Admin UI Extension |
|---------------------|-------------------|
| Navigate to app → Onboarding → Products → Images | Open product → Configure inline |
| Bulk selection (good for initial setup) | Per-product (good for ongoing management) |
| Separate workflow | Integrated into existing workflow |
| 3-step wizard | Single-step configuration |

**Best Practice**: Use **dashboard onboarding** for initial bulk setup, then use the **admin extension** for ongoing per-product adjustments.

## API Endpoint Details

### GET `/app/api/vto-product-config`

**Query Parameters**:
- `productId` (required) — Product GID or numeric ID

**Response** (200 OK):
```json
{
  "enabled": true,
  "productId": "gid://shopify/Product/123",
  "selectedImageId": "gid://shopify/ProductImage/456",
  "selectedImageUrl": "https://cdn.shopify.com/...",
  "productTitle": "Cool T-Shirt"
}
```

**Response** (404 — No config exists):
```json
{
  "enabled": false,
  "productId": "gid://shopify/Product/123",
  "selectedImageId": "",
  "selectedImageUrl": ""
}
```

### POST `/app/api/vto-product-config`

**Request Body**:
```json
{
  "productId": "gid://shopify/Product/123",
  "productTitle": "Cool T-Shirt",
  "isEnabled": true,
  "selectedImageId": "gid://shopify/ProductImage/456",
  "selectedImageUrl": "https://cdn.shopify.com/...",
  "productImage": "https://cdn.shopify.com/..."
}
```

**Response** (200 OK):
```json
{
  "success": true,
  "message": "VTO configuration saved successfully"
}
```

## Troubleshooting

### Extension not appearing
- Check that `shopify app dev` is running
- Verify the extension is deployed: `shopify app deploy`
- Check browser console for errors

### API calls failing
- Verify the backend route exists: `app/routes/app.api.vto-product-config.jsx`
- Check network tab for 404 or 500 errors
- Ensure Shopify session is valid (admin authentication)

### Data not saving
- Check database connection (PostgreSQL)
- Verify `ProductVtoConfig` model exists in Prisma schema
- Check server logs for Prisma errors
